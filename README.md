# Alzheimer's Disease Classification from Brain MRI with Cognitive Assessment and Explainable AI

## 🎓 Final Year Academic Engineering Project

A comprehensive, full-stack, deep learning-powered medical informatics system combining 4-class Brain MRI classification, Explainable Artificial Intelligence (Grad-CAM), multi-domain interactive cognitive assessments, and automated clinical-style progress and diagnostic report generation.

---

## ⚠️ Academic and Medical Disclaimer
> **IMPORTANT NOTICE:** This application is developed strictly for **academic, educational, and research purposes**. The predictions generated by the Convolutional Neural Network (CNN), activation heatmaps rendered by Grad-CAM, and scores derived from the educational cognitive questionnaire **do not constitute clinical diagnoses or medical advice**. Clinical interpretation of neuroimaging data must always be performed by licensed neurologists, radiologists, and qualified healthcare professionals.

---

## 🌟 Key Features

1. **4-Class Deep Learning MRI Classifier:**
   - Classifies structural Brain MRI axial scans into four distinct stages:
     - **Non-Demented** (Healthy Controls)
     - **Very Mild Demented** (Early Subtle Cognitive Changes)
     - **Mild Demented** (Noticeable Memory & Cognitive Impairment)
     - **Moderate Demented** (Advanced Neurodegeneration)
   - Evaluated rigorously with Accuracy, Precision, Recall, F1-Score, and Confusion Matrix.

2. **Explainable AI (Grad-CAM):**
   - Implements gradient-weighted Class Activation Mapping (Grad-CAM).
   - Generates high-resolution heatmaps highlighting the exact cerebral regions (e.g., hippocampus, ventricular enlargement, temporal lobe cortical thinning) guiding the CNN's classification.
   - Side-by-side comparative visualization with alpha-blended overlays.

3. **Multi-Domain Educational Cognitive Assessment:**
   - 5 structured cognitive domains:
     - Memory & Recall
     - Attention & Working Memory
     - Orientation (Time & Place)
     - Language & Semantic Fluency
     - Abstract Reasoning & Visuospatial Ability
   - Step-by-step interactive questionnaire with real-time scoring.

4. **Enterprise Architecture & Security:**
   - **Backend:** Python Flask with modular Blueprints and clean Service/Repository patterns.
   - **Database:** MySQL Server with relational schema, primary/foreign keys, and parameterized query security.
   - **Authentication:** Salted & hashed passwords using `Werkzeug` security and session isolation.
   - **Export:** Comprehensive PDF medical-style reports generated on-the-fly using `ReportLab`.

5. **Modern Medical Tech UI/UX:**
   - White and light-blue clinical theme built on Bootstrap 5 and Chart.js.
   - Interactive analytics, longitudinal prediction history, and assessment trend charts.

## 🚀 Setup & Execution Guide

### 1. Prerequisites
- Python 3.12+
- MySQL Server 8.0 or 8.4 running locally on port 3306

### 2. Virtual Environment Setup
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 3. Database Setup
Create database and initialize schema:
```powershell
python database/init_db.py
```

### 4. Machine Learning Pipeline
1. Download dataset into `data/raw/`
2. Run preprocessing:
   ```powershell
   python ml/dataset_preprocessing.py
   ```
3. Train CNN model:
   ```powershell
   python ml/train_cnn.py
   ```
4. Evaluate model & generate Grad-CAM metrics:
   ```powershell
   python ml/evaluate_cnn.py
   ```

### 5. Launch the Web Application
```powershell
python run.py
```
Open your browser and navigate to: `http://localhost:5000`
